## Figure-integrity rules for v1.1

1. **No figure may plot the benchmark-adjusted p = 0.03707 as the headline magnitude result.** The
   primary is `primary_magnitude_abs_day_return` at p = 0.0662.
2. **No figure may place the Appendix A.3 mechanism-stability effect (d = 1.294) on the same axis as
   the matched Level-1 estimate** without an explicit non-comparability caption. Different comparison
   groups, unmatched design, no stored interval.
3. **No figure may present the 0.8543% standalone return as attention performance.** The same drift
   existed without the attention filter.
4. **Any interval shown for the primary clustered model must show it crossing zero.** Truncating the
   axis to hide the crossing would misrepresent the result.
5. **No figure may depict prospective HYP-01 data.** None exists.
